# Olef Cloud Plugin for Claude Code

Create, schedule, and orchestrate Olef Cloud agents, workspaces, threads, event
workflows, native agent skills, and your Olef inbox directly from Claude Code.

## Requirements

- `ocloud` CLI (`brew install olef-dev/tap/ocloud`)
- Signed in via `ocloud login`

## Try it

- *"Create a cloud agent for me"*
- *"Ask my cloud agent what the capital of France is"*
- *"In 1 minute, send me Hello world via my cloud agent"*
- *"Watch my Olef inbox for new replies"*
